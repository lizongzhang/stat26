2.2 调查数据 Survey Data

调查是获取一手数据最常用的方法之一。

主要环节包括：

  1. 明确调查目的与问题
  2. 确定调查对象与抽样框
  3. 设计问卷或调查表
  4. 选择调查方式（面访、电话、网络、邮寄等）
  5. 实施调查与数据收集
  6. 数据审核与整理

调查方式常见分类

  • 全面调查（普查）
  • 非全面调查
    • 抽样调查
    • 重点调查
    • 典型调查

在实际研究中，抽样调查最为常用。

抽样调查

  • 总体（Population）
  • 样本（Sample）
  • 抽样框（Sampling frame）
  • 抽样方法
    • 简单随机抽样
    • 分层抽样
    • 整群抽样
    • 系统抽样
    • 多阶段抽样

总体（Population）

定义：
我们想要研究的全部对象所构成的集合。

例子： - 想了解某大学所有在校本科生的平均每周学习时间
→ 总体 = 该大学全部在校本科生 - 想研究全国高考考生的数学成绩分布
→ 总体 = 当年全部高考考生

注意：总体可以是有限的，也可以是无限的（理论上）。

样本（Sample）

定义：
从总体中抽取的一部分个体，用来推断总体特征。

例子： - 从某大学 2 万名本科生中，随机抽取 500 人进行问卷调查
→ 这 500 人就是样本 - 从全国高考考生中抽取 1 万人的成绩进行分析
→ 这 1 万人就是样本

核心思想：用样本的信息去估计总体的未知特征（如均值、比例等）。

抽样框（Sampling Frame）

定义：
实际用于抽样的完整名单或名录，是连接总体与样本的桥梁。

理想情况：抽样框 = 总体
实际情况：抽样框常常与总体不完全一致

例子： - 调查某市居民对公共交通的满意度
- 理想总体：全市所有常住居民
- 实际抽样框：可能是该市固定电话号码簿、或某平台注册用户名单

常见问题： - 覆盖不全（有些人没被列入） - 包含不合格对象（已搬走、已去世等） - 重复登记

抽样方法总览

常见概率抽样方法：

  1. 简单随机抽样（Simple Random Sampling）
  2. 分层抽样（Stratified Sampling）
  3. 整群抽样（Cluster Sampling）
  4. 系统抽样（Systematic Sampling）
  5. 多阶段抽样（Multi-stage Sampling）

简单随机抽样（Simple Random Sampling）

定义：
总体中每一个个体被抽中的概率完全相同，且抽取过程相互独立（或等概率无放回）。

优点：简单、统计理论性质好
缺点：需要完整抽样框；当总体很大时实施成本高

分层抽样（Stratified Sampling）

定义：
先将总体按照某个特征分成若干互不重叠的层（strata），再从每一层中独立进行随机抽样。 优点： - 保证各层都有代表性 - 通常能提高估计精度 - 可对每层单独分析

适用情况：总体内部差异较大，且可按重要特征分层时。

3. 整群抽样（Cluster Sampling）

定义：
先将总体分成若干群（clusters），然后随机抽取一部分群，对抽中的群进行全部调查（或再抽样）。

例子： 想调查某市小学生的视力情况。
以“学校”为群，随机抽取 20 所小学，然后调查这 20 所小学的全部学生。

优点：实施方便、节省成本（尤其当个体分散时）
缺点：精度通常低于简单随机抽样（因为同一群内个体往往较相似）

4. 系统抽样（Systematic Sampling）

定义：
将总体按一定顺序排列，先随机确定一个起点，然后按固定间隔抽取个体。

操作步骤： 1. 计算抽样间隔 \(k = N/n\)（总体量 / 样本量） 2. 在 1 ~ \(k\) 中随机选一个起点 3. 之后每隔 \(k\) 个抽取一个

例子： 某流水线每天生产 1000 件产品，想抽 50 件检验。
间隔 \(k = 1000/50 = 20\)。
随机选第 7 件作为起点，然后抽第 27、47、67…件。

优点：操作简单、样本分布较均匀
缺点：如果总体有周期性，可能产生偏差

5. 多阶段抽样（Multi-stage Sampling）

定义：
分多个阶段进行抽样，每个阶段使用不同的抽样单位。

典型例子（全国性入户调查）： 1. 第一阶段：抽取省份 / 城市 2. 第二阶段：在抽中的城市中抽取区县 3. 第三阶段：在抽中的区县中抽取街道 / 村 4. 第四阶段：在抽中的街道中抽取住户

优点：特别适合大规模、分散的总体，成本可控
缺点：设计与方差估计较复杂

抽样方法对比小结

方法 核心特点 优点 主要局限
简单随机抽样 每个个体等概率 理论简单、公平 需要完整名单，成本高
分层抽样 先分层再抽样 精度高、代表性好 需要分层变量信息
整群抽样 抽取整群并调查群内全部 实施方便、省钱 精度较低
系统抽样 等间隔抽取 操作简单、分布均匀 怕周期性波动

2.4 数据的误差

数据误差主要分为两大类：

抽样误差（Sampling error）

  • 由随机抽样引起

  • 可以计算和控制

  • 样本越大，抽样误差通常越小

非抽样误差（Non-sampling error）

  • 人为因素引起

  • 往往更难发现和控制

非抽样误差的主要来源

  • 覆盖误差：抽样框不完整或不准确
  • 无回答误差：拒访、找不到被调查者
  • 测量误差：问卷设计不当、访问员偏差、被访者记忆偏差
  • 处理误差：编码、录入、数据清洗错误

减少误差的主要措施

  • 完善抽样框
  • 提高回答率（激励、多次回访）
  • 规范问卷设计与访问流程
  • 加强访员培训与督导
  • 数据双录与逻辑校验
  • 对缺失值和异常值进行审慎处理

数据质量评价的基本维度

  • 准确性（Accuracy）
  • 完整性（Completeness）
  • 及时性（Timeliness）
  • 一致性（Consistency）
  • 可比性（Comparability）

好的数据是统计分析可靠的前提。
